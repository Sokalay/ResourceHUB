# Project Working Agreement

Read `PROJECT_CHECKLIST.md` before starting meaningful project work.

For every meaningful feature, fix, or project decision:

1. Add or locate its task in `PROJECT_CHECKLIST.md`.
2. Keep the current phase, overall status, next action, and blockers accurate.
3. Run checks appropriate to the change.
4. Mark a task complete only after its acceptance criteria pass.
5. Record follow-up work and newly discovered problems.
6. Update the Session Handoff before ending the work session.

Commit checklist updates together with the implementation they describe. Also update `README.md` when setup, scope, architecture, or user workflows change.
